This is an isolated development environment. Runtime state and credentials belong
outside it. Envoy supplies authentication; the placeholder is deliberately public.

Use Lore for version control. Do not initialize Git, change remotes, or request
credentials. Read the repository's AGENTS.md and nested rules before editing.
Use `lore -P` to disable the pager. Consult `lore --help` and subcommand help.
Work on a task branch, record small coherent commits, and push that branch.
Protected main is merged by a separate reviewer. Do not deploy or attempt to
modify protected main. Do not put AI or tool attribution in commits.

Build and test inside this container. It has no Docker socket: run the component's
Dockerfile check commands directly when asked, with private local test fixtures.
Report exactly which checks ran and which did not. Never claim a gate passed
without its result. Do not run other agents or external integrations.
